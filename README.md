# Weather Application

## Prodigy InfoTech Internship – Task 5

### About the Project
This is a Weather Application developed as part of my Prodigy InfoTech Web Development Internship.

The application allows users to search for different cities and view their current weather information using a weather API.

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Weather API

### Features
- Search weather by city name
- Display current temperature
- Show weather conditions
- Display humidity information
- Display wind speed
- Weather icons
- Responsive user interface

### How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Search for a city to view its weather.
